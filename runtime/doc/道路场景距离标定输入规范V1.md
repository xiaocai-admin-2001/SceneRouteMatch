# 道路场景匹配输入说明（V1）

场景基准图不再上传到本服务，也不再维护本服务的 `scene` 目录。

匹配时，服务根据 `camera_id` 自动查询：

```http
GET http://10.88.4.37:9091/api/oauth/v3/marker/calibration/highway_scene_images?camera_id=<camera_id>
```

查询结果需要包含：

```json
{
  "code": 200,
  "data": {
    "camera_id": "12663",
    "images": [
      {
        "id": "29751949712753701",
        "imagePath": "/mnt/data/sda/oauth/images/.../scene.jpg",
        "result": "1",
        "direction": "向上上行-向下下行",
        "distances": [
          {"y": 198, "distance": 50}
        ]
      }
    ]
  }
}
```

要求：

- `imagePath` 必须是运行机可读取的本地绝对路径。
- `id` 为该图片的标定记录 ID，匹配成功后原样输出。
- `result` 为 `0`、`1` 或 `2`。
- `distances` 为该图片对应的 Y 坐标距离数组。
- 图片新增、修改和删除统一由 9091 标定服务维护。

客户端只调用匹配接口：

```http
POST /api/test/highway_road_match
Content-Type: multipart/form-data
```

```bash
curl -X POST "http://<host>:19000/api/test/highway_road_match" \
  -F 'data={"camera_id":"12663","threshold":0.3}' \
  -F "image=@client.jpg"
```
