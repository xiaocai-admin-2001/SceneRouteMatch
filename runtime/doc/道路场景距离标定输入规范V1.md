# 道路场景图片输入接口协议（V1）

> Base URL：`http://<host>:19000`

## 1. 上传图片数据

```http
POST /api/test/highway_scene_image
Content-Type: multipart/form-data
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data` | JSON | 是 | 相机、图片名称和距离信息 |
| `image` | file | 是 | 基准图片文件 |

`data`：

```json
{
  "camera_id": "7543",
  "image": "1_preset_01_left.jpg",
  "result": "1",
  "direction": "向上上行、向下下行",
  "distances": [
    {"y": 520, "distance": 50},
    {"y": 680, "distance": 30},
    {"y": 840, "distance": 15}
  ]
}
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `camera_id` | string | 相机编号 |
| `image` | string | 图片保存名称 |
| `result` | string | 输入端定义的结果：`0`、`1` 或 `2` |
| `direction` | string | 行驶方向：`向上上行、向下下行` 或 `向上下行、向下上行` |
| `distances` | array | 图片对应的距离数据 |
| `distances[].y` | number | 图片中的 Y 坐标 |
| `distances[].distance` | number | 对应距离，单位米 |

坐标原点为图片左上角，Y 轴向下。同一张图片可配置多组距离。

请求示例：

```bash
curl -X POST "http://<host>:19000/api/test/highway_scene_image" \
  -F 'data={"camera_id":"7543","image":"1_preset_01_left.jpg","result":"1","direction":"向上上行、向下下行","distances":[{"y":520,"distance":50},{"y":680,"distance":30},{"y":840,"distance":15}]}' \
  -F "image=@1_preset_01_left.jpg"
```

成功响应：

```json
{
  "status_code": 200,
  "msg": null,
  "data": {
    "camera_id": "7543",
    "image": "1_preset_01_left.jpg",
    "result": "1",
    "direction": "向上上行、向下下行",
    "distances": [
      {"y": 520, "distance": 50},
      {"y": 680, "distance": 30},
      {"y": 840, "distance": 15}
    ]
  }
}
```

同一 `camera_id + image` 再次上传时，覆盖原图片和距离数据。

## 2. 删除图片数据

```http
DELETE /api/test/highway_scene_image?camera_id=7543&image=1_preset_01_left.jpg
```

按 `camera_id + image` 精确删除图片及该图片对应的结果、方向和距离信息。

请求示例：

```bash
curl -X DELETE "http://<host>:19000/api/test/highway_scene_image?camera_id=7543&image=1_preset_01_left.jpg"
```

成功响应：

```json
{
  "status_code": 200,
  "msg": null,
  "data": {
    "camera_id": "7543",
    "image": "1_preset_01_left.jpg",
    "deleted": true
  }
}
```

图片不存在时返回 `404`。

## 3. 查询全部维护数量

```http
GET /api/test/highway_scene_images
```

响应：

```json
{
  "status_code": 200,
  "msg": null,
  "data": {
    "camera_count": 19,
    "image_count": 1384,
    "configured_count": 0,
    "cameras": [
      {
        "camera_id": "7543",
        "image_count": 72,
        "configured_count": 0
      }
    ]
  }
}
```

## 4. 查询指定相机

```http
GET /api/test/highway_scene_images?camera_id=7543
```

响应：

```json
{
  "status_code": 200,
  "msg": null,
  "data": {
    "camera_id": "7543",
    "image_count": 1,
    "configured_count": 1,
    "images": [
      {
        "image": "1_preset_01_left.jpg",
        "result": "1",
        "direction": "向上上行、向下下行",
        "distance_count": 3,
        "distances": [
          {"y": 520, "distance": 50},
          {"y": 680, "distance": 30},
          {"y": 840, "distance": 15}
        ]
      }
    ]
  }
}
```

| 字段 | 说明 |
|------|------|
| `camera_count` | 已维护相机数量 |
| `image_count` | 已维护图片数量 |
| `configured_count` | 已配置距离信息的图片数量 |
| `distance_count` | 单张图片配置的距离数量 |
