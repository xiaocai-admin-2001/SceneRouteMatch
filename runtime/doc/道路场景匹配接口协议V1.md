# 道路场景匹配接口协议（V1）

> Base URL：`http://<host>:19000`

## 1. 匹配接口

```http
POST /api/test/highway_road_match
Content-Type: multipart/form-data
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data` | JSON | 是 | 请求参数 |
| `image` | file | 是 | 待匹配实时图片 |

`data`：

```json
{
  "camera_id": "5476"
}
```

| 参数 | 说明 |
|------|------|
| `camera_id` | 相机编号 |
置信度不允许由请求端传入。Hybrid 特征阈值和道路 IoU 阈值统一由服务端配置维护。

## 2. 判断逻辑

### 2.1 道路和特征均匹配

特征分达到 `threshold`，且实时图和最佳场景图的道路 IoU 达到 `road_threshold`：

```text
match_mode = road_feature_direct
```

直接输出场景图原始标定的 `y-distance`。

### 2.2 仅特征匹配

特征分达到阈值，但道路 IoU 未达到阈值：

1. 对原场景图每个标定 Y，取上下各 100 像素范围内的 LoMa 匹配点。
2. 将原 Y 映射到实时图片的新 Y。
3. 每条线至少需要 4 个有效匹配点。
4. 映射后的 Y 必须保持原顺序。
5. 至少成功映射 2 条距离线。

成功时：

```text
match_mode = feature_recalibrated
```

### 2.3 均不匹配

特征分不足，或道路不匹配且距离线重标定失败：

```text
match_mode = no_match
```

不输出场景图、标定 ID、方向和距离。
