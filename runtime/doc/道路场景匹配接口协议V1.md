# 道路场景匹配接口协议（V1）

> Base URL：`http://<host>:19000`

## 1. 匹配接口

```http
POST /api/test/highway_road_match
Content-Type: multipart/form-data
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data` | JSON | 是 | 请求参数 |
| `image` | file | 是 | 客户端待匹配图片 |

`data`：

```json
{
  "camera_id": "7543",
  "threshold": 0.3
}
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `camera_id` | string | 相机编号 |
| `threshold` | number | 特征匹配阈值，不传时默认 `0.3` |

请求示例：

```bash
curl -X POST "http://<host>:19000/api/test/highway_road_match" \
  -F 'data={"camera_id":"7543","threshold":0.3}' \
  -F "image=@client.jpg"
```

## 2. 匹配逻辑

1. DINOv3 对该相机的全部场景图进行粗排。
2. LoMa 对 DINOv3 Top-2 候选进行局部特征和几何匹配。
3. 返回综合分最高且达到 `threshold` 的图片。
4. 从该图片配置中读取 `result`、`direction` 和 `distances`。
5. 不再调用道路轮廓分割接口，不再进行道路 IoU 比对。

## 3. 成功响应

```json
{
  "status_code": 200,
  "msg": null,
  "data": {
    "camera_id": "7543",
    "result": "1",
    "best_image": "1_preset_01.jpg",
    "total_score": 0.9568,
    "direction": "向上上行、向下下行",
    "distances": [
      {"y": 520, "distance": 50},
      {"y": 680, "distance": 30}
    ]
  }
}
```

| 字段 | 说明 |
|------|------|
| `result` | 最佳图片由输入端维护的 `0`、`1` 或 `2` |
| `best_image` | 最佳匹配图片名称 |
| `total_score` | Hybrid 特征综合得分 |
| `direction` | 最佳图片维护的方向 |
| `distances` | 最佳图片维护的 Y 坐标距离数组 |

未达到阈值时：

```json
{
  "status_code": 200,
  "msg": null,
  "data": {
    "camera_id": "7543",
    "result": "0",
    "best_image": null,
    "total_score": 0,
    "direction": null,
    "distances": []
  }
}
```

## 4. 错误响应

```json
{
  "status_code": 400,
  "data": null,
  "msg": "错误信息"
}
```

| HTTP | 说明 |
|------|------|
| `400` | 参数或图片无效 |
| `404` | 相机不存在或没有场景图 |
| `500` | 特征服务或模型推理失败 |

每次响应单独保存在：

```text
/opt/RoadSegmentTestService/logs/responses/YYYYMMDD/
```
